# CPU BCST numerical demonstration

Requires Python 3.10 or newer, NumPy and SciPy; no GPU or PyTorch.
Run:

```sh
python launch_demo.py
```

On Windows, double-click `run_demo.cmd`; the terminal stays open to display
the results. On macOS or Linux, run `sh run_demo.sh`. The launcher installs
missing dependencies in a private `.venv` on its first run. With dependencies
already installed, you can also run `python run_demo.py` directly.

## Input and settings

`instance.json` defines a three-site path A–B–C with four channels and site
cardinalities `(1,2,1)`. Each channel must be used once across the three sites,
and adjacent sites cannot share a channel. The 12-qubit state is simulated
exactly in its 96-dimensional fixed-cardinality sector. There are twelve
feasible configurations and one optimum, with objective value 24.

`C` counts adjacency conflicts; `Q` is the sum of squared channel-quota
deviations. The objective `O` is the assignment cost plus 256 times the
third-order-intermodulation penalty, constructed in `simulate.py`.

| Circuit | Depth | Phase separator | Energy loss | Mixer |
| --- | --- | --- | --- | --- |
| LP stage 1 | 3 | `C/2` | `C` | Within-site XY |
| LP stage 2 | 2 | `Q` | `Q` | Learned projector |
| LP stage 3 | 4 | `O/256` | `(O + 1024(C+Q))/256` | Learned projector |
| Block-XY QAOA | 4 | `(O + 1024(C+Q))/256` | Same as its separator | Within-site XY |

The complete XY generator is `sum((XX+YY)/2)` over channel pairs within each
site. Its exponential is evaluated exactly. Each LP mixer is generated by
`I - |Phi><Phi|`, using the preceding optimized state frozen throughout the
next stage. Every optimization uses three deterministic random starts and
L-BFGS-B with analytic adjoint gradients, for at most 160 iterations per start.
The restart with the lowest energy is selected. These are fixed demonstration
depths; LP-QAOA also optimizes its two structural stages separately.

Depths and optimizer settings can be edited in `instance.json`. To select an
input file explicitly, run `python launch_demo.py --instance path/to/instance.json`.

## Output and runtime

The terminal prints restart losses, LP stage probabilities, and a final
comparison of optimum probability, feasible probability and expected full
energy. It writes no result files and opens no browser.

The default optimum probabilities are approximately 26.05% for LP-QAOA and
4.89% for block-XY QAOA. A complete run took about one second on the development
CPU, using Python 3.13.12, NumPy 2.4.4 and SciPy 1.17.1. This small demonstration
is separate from the paper's experimental data.
